# Frontend Guide

## Overview
This document explains how the front-end is structured and how to run it locally.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- MUI (Material UI) + Emotion

## Local Development
1. Install dependencies: `npm install`
2. Start the dev server: `npm run dev`
3. Open `http://localhost:3000`

## Key Paths
- `src/app`: Routes, layouts, and global styles
- `src/fe`: Feature modules and UI components
